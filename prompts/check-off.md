# Prompt

Build only user story 5: check off.
- Each planned event shows a checkbox on the list page and detail page.
- Clicking it toggles completed true/false and saves immediately, without a full page reload.
- Completed events show a checkmark and faded text.
When done, create prompts/check-off.md with this prompt and a summary.

# Summary

Added completion checkboxes for planned events on the list and detail pages. Toggling a checkbox saves the completed state immediately through an authenticated request, with the server restricting updates to the signed-in user's planned events. Completed events show a checkmark and faded text without a full page reload.
